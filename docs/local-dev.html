Guía de desarrollo local

CTS Dashboard v3 · FastAPI + React/Vite + PostgreSQL + Salesforce

Prerequisitos

HerramientaVersiónComprobar
Python3.10+python3 --version
Node.js18+node --version
npm9+npm --version
AWS CLI v22.xaws --version
SSO profile juanconfiguradoaws configure list-profiles

Instalar dependencias (una sola vez)

# Backend (Python)
pip install -r backend/requirements.txt

# Frontend (Node)
cd frontend && npm install

Primera vez

  1. AWS SSO Login
    aws sso login --profile juan

    Se abre el navegador → autorizas → vuelves a la terminal. Las credenciales duran ~8 horas.

  2. Generar backend/.env
    python3 scripts/gen_local_env.py

    Lee secretos de AWS Secrets Manager (DB, Salesforce OAuth, Google API, Anthropic) y los escribe en backend/.env. El archivo está en .gitignore y nunca se commitea.

  3. Arrancar todo
    # Primera vez — hace SSO login + genera .env + arranca
bash scripts/dev.sh --login
  4. Login en la aplicación (OAuth Salesforce)

    Ve a http://localhost:5173 → haz clic en Login en el header → OAuth de Salesforce → vuelves logado automáticamente.

Atajo
bash scripts/dev.sh --login hace los tres primeros pasos en una sola línea: SSO login, gen .env, arrancar.

Uso diario

# .env ya existe y sigue válido:
bash scripts/dev.sh

# Si quieres refrescar los secretos antes de arrancar:
bash scripts/dev.sh --setup

# SSO expirado (pasan ~8h):
bash scripts/dev.sh --login

El script comprueba prerequisitos, mata procesos huérfanos en los puertos 8000/5173, arranca el backend con 4 workers, espera a que responda, arranca el frontend (Vite), y abre el navegador automáticamente.

⚠ 4 workers obligatorios
El backend necesita 4 workers (no 1) porque Moby hace llamadas HTTP internas a /api/explorer/search desde dentro del mismo proceso. Con un solo worker esa llamada hace deadlock.

Login con Salesforce

El backend usa OAuth 2.0 con refresh token. El flujo completo es:

Navegador → http://localhost:5173  → click Login
         → http://localhost:8000/api/salesforce/auth
         → redirect → login.salesforce.com  → autorizas
         → callback → http://localhost:8000/api/salesforce/oauth/callback
         → sesión guardada en DB (tabla sf_sessions)
         → redirect → http://localhost:5173
Persistencia de sesión
La sesión se guarda en PostgreSQL (sf_sessions), por lo que sobrevive reinicios del backend. Sin embargo, el token de acceso de Salesforce expira en ~15–20 min de inactividad. Si ves errores "Salesforce session required", simplemente vuelve a hacer Login.

Verificar sesión activa

curl -s http://localhost:8000/api/salesforce/me \
  --cookie "sf_session=<valor_de_la_cookie>" | jq .

Moby AI

Moby usa claude-sonnet-4-6 vía API de Anthropic. Requiere:

  • Sesión Salesforce activa (para consultar datos en tiempo real)
  • ANTHROPIC_API_KEY en backend/.env (se obtiene automáticamente)

Cómo usarlo

  1. Ir a la tab Chat
  2. Escribir en español o inglés
    ¿Cuántos sitios Stage 2 hay en España?
List the 10 closest sites to Madrid with overnight stay
dame sitios a menos de 150 km de Berlin con farmacia
  3. Ver la respuesta en streaming

    Las respuestas aparecen en tiempo real con el cursor ▋. Consultas complejas activan "extended thinking" (Moby tarda más pero da respuestas más precisas).

Features nuevas NEW

1
Members — Filtro multi-nombre
Tab /members · filtro de Institution name por múltiples valores (OR)
  1. Ir a la tab Members
  2. En "Institution name": escribe Munich → pulsa Enter → aparece chip azul
  3. Escribe Leuven → Enter → segundo chip
  4. Haz clic en Search → solo aparecen instituciones que contienen "Munich" o "Leuven"
  5. Haz clic en × en un chip para eliminarlo individualmente
  6. Clear → borra todos los filtros
2
Explorer — Nearby multi-site
Tab /explorer · encuentra sites cercanos a múltiples sitios de referencia a la vez
  1. Ir a la tab Explorer y hacer una búsqueda
  2. Marcar los checkboxes en 2–3 filas de la tabla (columna izquierda)
  3. Aparece el botón violeta "Nearby (N selected)" en la toolbar de resultados
  4. Hacer clic → modal de km → ajustar el radio → Apply
  5. El panel lateral muestra todos los sites de INNODIA a X km de cualquiera de los seleccionados
  6. La cabecera del panel dice Nearby · N selected sites

Troubleshooting

backend/.env not found

aws sso login --profile juan
python3 scripts/gen_local_env.py

ExpiredTokenException de AWS

El token SSO ha expirado (~8 horas de vida):

bash scripts/dev.sh --login

Puerto ya en uso

El script lo resuelve automáticamente. Si persiste:

lsof -ti tcp:8000 | xargs kill -9
lsof -ti tcp:5173 | xargs kill -9

Explorer da 500 / 503

La sesión Salesforce ha expirado. Ve a http://localhost:5173 → Login.

Moby no responde o error Anthropic

# Comprobar que la key está en .env
grep ANTHROPIC_API_KEY backend/.env

# Si falta, regenerar .env
bash scripts/dev.sh --setup

El frontend muestra datos de producción

Ojo
El backend local se conecta a la misma PostgreSQL de producción (AWS RDS). Los datos que ves y modificas son reales. Ten cuidado al probar escrituras.
